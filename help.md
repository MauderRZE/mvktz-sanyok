# Запуск тестів у проєкті

Для перевірки працездатності бази даних та конфігурації проєкту використовуйте наступні команди.

## Основні команди

### 1. Запуск усіх тестів
Запускає повний пакет тестів (схему БД, зв'язки, цілісність та базовий приклад):
```bash
./vendor/bin/phpunit
```
або через Artisan:
```bash
php artisan test
```

---

## Запуск окремих тестів

### 2. Перевірка наявності таблиць та доступності моделей
Перевіряє, чи існують усі 22 таблиці в базі даних та чи кожна Eloquent-модель може виконати запит:
```bash
./vendor/bin/phpunit --filter DatabaseSchemaTest
```

### 3. Перевірка зв'язків між моделями (Eloquent Relations)
Перевіряє коректність конфігурації зв'язків (belongsTo, hasMany тощо) на всіх моделях:
```bash
./vendor/bin/phpunit --filter DatabaseRelationshipsTest
```

### 4. Перевірка цілісності даних та готовності до продакшену (Production Readiness)
Перевіряє відсутність осиротілих записів (порушення зовнішніх ключів), наявність індексів на ключових стовпцях та безпекову конфігурацію:
```bash
./vendor/bin/phpunit --filter ProductionReadinessTest
```
